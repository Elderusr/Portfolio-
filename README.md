# Emmanuel YAHI — Portfolio

Backend developer portfolio built with React 19, Vite, and Tailwind CSS.

**Live:** [portfolio-elderusr.vercel.app](https://portfolio-elderusr.vercel.app)

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 3
- AOS (scroll animations)
- react-icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
